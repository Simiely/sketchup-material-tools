## 结论三问

1. **链路逻辑通顺吗？** 通顺。主链 run→merge_entities→merge_bucket 与 13/15 素材预期一致；数据安全（失败不删、回滚、批量删除回退）设计到位。
2. **是补丁叠补丁吗？** 否。v2 重构后事务（start/commit/abort）、失败处理（failed 数组）、清理（purge）各司其职、单点归属清晰。
3. **会无法操作/出 bug 吗？** 正常顶层使用不会；**编辑态运行会出位置错乱/崩溃（P-01 必修）**；组件为主的模型合并分组有语义偏差（P-02）。
