# 按材质合并插件 (Material Merger) v2.7.1

把相同材质的组/组件合并成一个大组，并可选清理未使用的组件定义，从而减小 SKP 文件体积。

## v2.7.1 更新说明（功能拆分）

- 「导出到 Blender」功能已迁移至**独立插件 `su_blender_export.rb`**（含贴图转英文功能），本插件专注合并 + 清理。

## v2.6 更新说明（独立清理按钮）

- **控制面板新增「清理未使用数据」按钮**：不合并、直接清理模型中所有未被引用的组件定义（合并前/后随时可用）。
- 点击后先确认（官方数据安全要求），执行后结果显示在面板状态区；出错自动回滚。
- 菜单同步新增 `扩展程序 > 按材质合并 > 清理未使用数据...` 入口。
- 与合并共用防重入标志：合并进行中点击会提示等待。

## v2.5 更新说明（修复"点开始合并就卡死"）

- **分块粒度下沉到单个实体**：之前分块只发生在"材质桶"之间——一个桶内所有实体会在同一个时间片里循环处理，当某个材质下有海量实体（几万~几十万个，组件模型很常见）时，单块长时间占满主线程 → 界面卡死。
- 现在**每个时间片逐实体处理**（单实体复制是毫秒级原子操作），无论模型多大、单桶多庞大，界面都会每 0.15 秒呼吸一次，不再卡死。
- 注：插件**没有**"拆分模型"前置步骤；`explode`（炸开）只是合并桶时的内部操作。

## v2.4 更新说明（控制面板）

- **常驻控制面板窗口**：一个「开始合并」按钮 + 取消按钮 + 进度条 + 状态显示区。
- **一键操作**：点「开始合并」即执行（框选范围优先，未选中则处理整个模型）；进行中进度条实时跳动（百分比 + 当前材质组名）；完成后结果显示在面板状态区（合并几组/移除几个/保留实例/清理定义）。
- **随时取消**：任务进行中点「取消」或直接关闭面板，整体回滚不留半成品。
- 入口：工具栏「控制面板」按钮 / 菜单 `扩展程序 > 按材质合并 > 控制面板...`；原有的「按材质合并」按钮、进度弹窗、状态栏均保留。

## v2.3 更新说明（解决大批量任务界面冻结）

- **异步分块执行**：大任务（≥100 实体）不再一口气跑完——改为**每块处理约 0.15 秒 → 让出事件泵（界面恢复响应、视图刷新）→ 链式调度下一块**，从根本上消除"SketchUp 卡死/未响应"。
- **随时可取消**：分块间隙事件泵持续运行，进度窗「取消」按钮实时生效；取消或出错都会整体回滚（abort_operation）。
- **防重入**：合并进行中重复点击会提示「已有任务正在进行」，不会叠加冲突。
- **小任务仍同步**：<100 实体合并很快，直接跑完，无需分块。

## v2.2 更新说明

- **进度弹窗**：待合并实体 ≥ 100 时弹出 HtmlDialog 进度条，实时显示**百分比 + 当前材质组名**（独立 WebView 渲染，不受同步执行阻塞）；小任务仍用状态栏显示（零开销）。
- **取消支持**：进度弹窗带「取消」按钮，取消后**整体回滚**（abort_operation），不留半成品；关掉弹窗同样视为取消。
- **兼容降级**：SketchUp 2017/2018（无 HtmlDialog）自动降级为状态栏模式，不影响使用。

## v2.1 更新说明

- **编辑态防护**：运行前检测是否处于组/组件编辑状态（`active_path`），是则提示先退出编辑——避免局部坐标导致的位置错乱，以及删除编辑路径内实体的潜在崩溃（对应 SketchUp 官方文档对 `erase_entities` 的限制）。
- **调试输出合规**：`puts` 调试输出改为 `DEBUG_MODE` 开关控制（默认关闭），符合官方 Extension Requirements。
- **分组规则明确**：见下方「合并规则」补充说明。

## v2.0 更新说明（重要）

- **修复 v1 致命 bug**：v1 使用了不存在的 API `transform_by_entities`，一运行就会报错。经核对 SketchUp 官方 API 文档与社区（官方 issue-tracker #41、论坛 "Copy entities" 帖）确认：官方 API 只有 `transform_entities`（移动变换），**没有直接复制实体的方法**。
- **重写合并核心**：采用社区验证的标准做法——`add_instance(定义, 变换) + explode`。这是 SketchUp **内核级整块复制**（一次调用复制整组几何，自动保留材质/图层/UV），把"每个实体一次 API 调用"变成"每个实体一次内核操作"，**大工程下性能提升数个数量级**。
- **组件实例智能保留**：源实体若是组件实例，在新组内保留为实例（共享组件定义——这是 SketchUp 最紧凑的存储方式，文件反而更小）；源实体若是组，则炸开合并为纯几何。
- **数据安全**：批量删除源实体（官方推荐 `erase_entities`）；复制失败的实体**不会删除**；出错时整体回滚（`abort_operation`），不留下半成品。
- **大工程体验**：3000+ 实体先弹预警；状态栏显示进度百分比；每 20 组刷新一次视图，避免"像卡死一样"的长时间无响应。

## 为什么能减小文件体积

- **合并实体**：模型里大量同材质的小组/组件实例（常见于 CAD 导入、重复摆放的构件），合并成一个组后实体数量大幅减少，冗余的组结构开销被消除。
- **清理未使用组件定义**：合并释放大量组件实例，随之产生大量"无实例引用"的定义仍占文件体积，插件可一键清掉（效果通常最明显）。
- 合并后建议再用 SketchUp 自带功能二次瘦身：`窗口 > 模型信息 > 统计信息 > 清理未使用项`（Purge Unused）。

> 注意：合并**不改变几何数量**（点/面/边不会凭空消失）。如果文件大是因为几何本身极多，瘦身效果有限，可配合「清理未使用项 + 纹理压缩」一起用。

## 安装

### 方式一：.rbz 安装包（推荐）

1. 在 SketchUp 中执行 `扩展程序 > Extension Manager`（扩展程序管理器）。
2. 点击左下角「安装扩展程序」。
3. 选择 `material_merger.rbz`，确认安装后重启 SketchUp。

### 方式二：手动拷贝 .rb

把 `material_merger.rb` 复制到插件目录，然后重启 SketchUp：

```
%APPDATA%\SketchUp\SketchUp 20xx\SketchUp\Plugins\
```

（macOS 为 `~/Library/Application Support/SketchUp 20xx/SketchUp/Plugins/`）

## 使用方法

1. **框选**要合并的组/组件（不选则自动处理整个模型的所有顶层组/组件）。
2. 点击工具栏按钮「按材质合并」，或菜单 `扩展程序 > 按材质合并 > 按材质合并...`。
3. 弹出确认框，询问是否同时清理未使用组件定义（建议选「是」）。
4. 状态栏会显示进度；完成后弹出统计结果。
5. 用 `Ctrl+Z` 可撤销（操作已加入撤销历史）。

## 大工程（几万~几十万实体）使用建议

- 合并过程是**同步执行**，期间界面暂时无响应是正常的（SketchUp Ruby 无法异步），请等状态栏进度走完，不要强杀进程。
- **关闭 Ruby Console 和 Outliner 窗口**再执行——官方社区确认：这两者在大模型下会显著拖慢一切操作（每次几何变化都触发刷新/日志）。
- 执行前**先另存一份**，并把「自动保存间隔」临时调大（`窗口 > 偏好设置 > 常规 > 自动保存`），避免合并中途触发自动保存。
- 合并 + 清理未使用定义后，用 `另存为` 输出新文件再对比体积。

## 合并规则

| 项 | 规则 |
|---|---|
| 分组依据 | 实体**顶层**材质（无材质的统一归入「默认材质」组） |
| 分组补充 | 组件实例若未覆盖材质（`实例.material` 为 nil），会归入「默认材质」组——即使其定义/面内有材质。组件为主的模型可能整体并入一个默认组；如需按定义材质分组，请告知作者增加选项 |
| 源 = 组 | 实例化其定义后炸开，几何按世界坐标合并进新组（纯几何合并） |
| 源 = 组件实例 | 在新组内保留为实例，共享组件定义（存储最紧凑） |
| 新组命名 | `合并_材质名`（如 `合并_白色`） |
| 材质保留 | 面独立材质随几何保留；无独立材质的面继承新组的组材质 |
| 撤销 | 支持（一次操作整体撤销）；出错自动回滚 |

- 若源实体内部有「部分面有材质、部分面继承组材质」的混合情况，合并后依赖组材质的面会继承新组的组材质（v2 已处理），一般无需重刷。
- 清理组件定义不可逆，插件保证只清理「无任何实例引用」的定义，不影响可见模型。

# 导出到 Blender 插件 v1.0.0（独立插件）

一键把 SketchUp 模型送进 Blender，并从根源解决"贴图丢失"问题。

## 功能

### 1. 贴图文件名转英文（解决贴图丢失）
- 遍历模型所有带贴图的材质，把贴图数据**导出为英文文件名**（`tex_0001.png` 形式，字母 + 序号，保证不重复）
- 存入**模型同目录的 `<模型名>_textures/` 文件夹**
- 材质**重新指向新文件**（自动恢复纹理尺寸与颜色）
- 已转换过的贴图自动跳过（幂等，重复执行无害）
- 原理：中文/空格贴图文件名在 DAE 导出 + Blender 导入时最容易丢失，转成纯英文后不再丢

### 2. 一键导出到 Blender
```
贴图转英文名 → 导出 Collada (.dae, 保留组件实例) → 自动启动 Blender 并导入
```
- 自动查找本机 Blender（常见安装路径 / `BLENDER_EXE` 环境变量，取最高版本）
- 非阻塞启动，SketchUp 不会卡住
- Blender 自动：清空默认场景 → 导入 DAE → 设公制单位 → 聚焦模型

## 使用

- 控制面板：`扩展程序 > 导出到 Blender > 打开面板...`（一键导出按钮 + 仅转换贴图按钮）
- 或直接：`扩展程序 > 导出到 Blender > 一键导出到 Blender...`
- 工具栏：「导出到 Blender」按钮

## 安装

两个文件必须同目录：
```
su_blender_export.rb        ← 主插件
su_to_blender_import.py     ← Blender 导入脚本（由主插件调用）
```
放 `%APPDATA%\SketchUp\SketchUp 20xx\SketchUp\Plugins\` 后重启 SketchUp。
（`su_blender_export.rbz` 安装包已内置这两个文件）

## 已知说明

- 模型必须先保存（贴图存放位置依赖模型路径）
- 大模型导出 DAE 需几秒~几十秒，期间 SketchUp 短暂无响应
- 贴图文件本身的格式/分辨率不变，只是文件名与位置改变
